SpaceOps take-home test: anomaly detection

Contents
  answers.pdf    answers to the questions
  plots/         the 20 plots (q1a_*, q1b_*, q1c_*, q3a_*, q3b_*)
  main.py        runs every question and prints the total run time
  telemetry.py   loading, cleaning and shared plot style
  q*.py          one module per question (q4_detectors.py: detection functions)

Run
  pip install -r requirements.txt
  python src/main.py

The CSV files are expected in a "Support Files" folder next to the scripts,
as in the folder that came with the test. Run time is about 20 s.
